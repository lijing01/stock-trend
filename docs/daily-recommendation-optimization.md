# “今日推荐”优化方案

> 状态：讨论稿
> 日期：2026-08-06
> 适用范围：`/candidates` 每日候选股、`/daily-review` 市场环境、`/wyckoff-backtest` 信号验证

## 落地计划

P0 逐任务实施计划见：
[`docs/superpowers/plans/2026-08-06-daily-recommendation-p0-reliability.md`](superpowers/plans/2026-08-06-daily-recommendation-p0-reliability.md)。

落地顺序固定为：

1. R0-A：修正回测收益窗口和基准样本。
2. R0-B：增加候选数据日期、覆盖率和推荐资格。
3. R0-C：让市场环境与盘中状态控制行动等级。
4. R0-D：使用热点绝对门槛，并按过滤后有效数量扩池。
5. P1：补齐交易计划、候选宇宙和完整生产链回测。
6. P2：保存不可变推荐快照并跟踪实际表现。

## 1. 背景与结论

当前“今日推荐”的生产链路为：

```text
当日热点板块
  → 板块成分股硬过滤
  → 维科夫买点漏斗
  → 动量/量价/资金/基本面/板块/维科夫复合评分
  → Top 30 每日候选表
```

该流程已经具备候选发现能力，但当前输出更接近“候选股排行榜”，尚不足以直接称为“今日推荐”。主要差距不在页面样式，而在以下四点：

1. 数据新鲜度和数据覆盖率没有成为推荐硬门槛。
2. 市场环境目前主要用于提示，没有真正约束推荐数量、仓位和行动等级。
3. 热点和复合评分尚未经过完整生产链回测校准。
4. 输出缺少入场区间、失效条件、止损、目标、仓位和有效期等执行要素。

优化目标应从“今天分数最高的股票”升级为：

> 在当前市场环境下，筛出证据充分、能够成交、风险边界明确，并经过历史验证的少数中线机会。

## 2. 当前实现观察

### 2.1 数据新鲜度风险

- `stock_scanner._fetch_kline()` 读取缓存时只检查记录数量，不检查最后交易日或缓存年龄，可能使用过期 K 线。
- 基本面缓存只检查是否包含 `summary`，没有报告期或更新时间校验。
- `load_regime_context()` 读取市场环境后返回 `data_date`，但不验证该日期是否为当前有效交易日。
- 盘中数据和收盘确认数据使用相同推荐语义，容易把未收盘信号当作正式信号。

### 2.2 热点板块偏差

- `pick_hot_sectors(top_n=20, min_hot=45, ...)` 中的 `min_hot` 当前未实际参与过滤。
- 板块热度经过全市场 min-max 归一化，即使市场整体很弱，也总会产生相对高分板块。
- 候选池主要使用当日板块热度，缺少 3/5/10 日持续性和相对基准强弱。
- 成分股接口按当日涨幅排序后只取前若干只，存在追涨偏差；所谓“板块内滞涨”也只是在这批涨幅靠前的股票中相对滞涨。

### 2.3 候选数量驱动扫描停止

- 扫描在维科夫候选数量达到 `min_candidates` 后停止。
- `min_score` 过滤发生在停止扫描之后，因此过滤后可能仍然候选不足。
- 当前排序没有行业集中度和相关性约束，Top 结果可能集中在同一主题。
- 股票属于多个板块时，去重逻辑只保留首次遇到的板块归属，可能丢失更强的主线解释。

### 2.4 缺失数据被视为中性数据

资金、基本面等数据缺失时通常返回 50 分。这会把“没有证据”和“证据中性”混为一谈，使复合分无法表达真实可信度。

建议将结果拆分为：

```text
raw_score              原始方向/强弱分
coverage               必检数据覆盖率
data_quality           数据质量与新鲜度
confidence             信号可信度
quality_adjusted_score 质量调整后的最终排序分
```

### 2.5 回测闭环不完整

现有 `/wyckoff-backtest` 主要验证维科夫买点，而不是完整的“热点板块→候选→复合排序→Top K”生产链。

需要优先复核两个实现细节：

- 前向收益命中目标日期时使用目标日期前一根 K 线，可能少计算一个交易日。
- 基准注释为“全部股票日”，实际在成功识别出维科夫阶段后才加入基准，基准样本可能存在选择偏差。

此外，当前模拟未纳入次日实际成交、涨停无法买入、手续费、滑点、止损和组合约束。

## 3. 目标产品形态

“今日推荐”应分成三层，而不是输出一张 20～30 只股票的等价列表。

### 3.1 今日可执行

最多 3～5 只，同时满足：

- 市场环境允许建仓。
- 板块具有绝对强度和持续性。
- 核心数据覆盖率达到门槛。
- 维科夫买点及复合评分通过历史校准阈值。
- 风险收益比达标，且不存在无法成交、重大事件临近等硬风险。

### 3.2 等待触发

逻辑成立，但价格尚未满足入场条件。明确给出：

- 突破确认价；或
- 回踩承接区间；以及
- 触发失效日期。

### 3.3 观察池

保留原有 20～30 只候选发现能力，但明确标注不能直接行动的原因，例如：

- 市场环境偏弱；
- 数据覆盖不足；
- 板块持续性不足；
- 距离支撑过远；
- 风险收益比不足；
- 重大事件临近。

## 4. 分级优化方案

## P0：可信度和正确性

### P0-1 数据新鲜度硬门槛

为行情、资金、基本面、市场环境统一增加：

- `data_date`
- `fetched_at`
- `source`
- `quality`
- `stale_reason`

推荐规则：

- K 线必须覆盖最近有效交易日。
- 市场环境必须匹配当前推荐所依据的交易日。
- 资金数据超过允许时效后降权或淘汰。
- 关键维度缺失时不得进入“今日可执行”。
- 盘中输出统一标记为“临时观察版”；正式推荐默认在收盘后生成，或盘前使用上一交易日收盘数据。

### P0-2 市场环境硬门控

建议规则：

| 市场环境分 | 输出等级 | 推荐数量 | 组合仓位上限 |
|---|---|---:|---:|
| `<60` | 仅观察 | 0 | 0% 或保持原持仓 |
| `60–79` | 等待触发/轻仓 | 0～2 | 20%～30% |
| `≥80` | 正常推荐 | 3～5 | 视风险预算确定 |
| 缺失/过期 | 降级 | 0 | 不给新增仓位建议 |

市场环境不应只是报告提示，而应直接影响候选是否可执行、推荐数量和仓位。

### P0-3 热点板块绝对门槛

同时保留绝对分和相对排名：

```text
sector_score =
  当日绝对热度
  + 3/5/10日持续性
  + 相对沪深300强弱
  + 资金持续性
  + 涨停/LHB共振
```

要求：

- 修复或移除未生效的 `min_hot` 参数。
- 禁止仅凭 min-max 后的相对高分认定强势板块。
- 区分“中期主线”“新兴主题”“单日脉冲”。
- 单日脉冲默认只进入观察池。

### P0-4 数据质量调整评分

不再用固定 50 分代表缺失数据。建议：

```text
final_score = raw_composite_score × coverage_factor × freshness_factor
```

最低要求示例：

- K 线：100% 必需。
- 资金或基本面：至少一个完整，另一个不得为错误状态。
- 市场环境：必须有效。
- 总覆盖率低于 70%：只能进入观察池。

### P0-5 修正并升级回测

先修正：

1. 前向收益持有期的精确日期定义。
2. 全样本基准的采样范围。
3. 测试用例必须断言精确收益值，而不只是断言返回浮点数。
4. 将 `test_wyckoff_backtest.py` 接入主质量门。

随后增加完整生产链回测：

```text
历史当日可见数据
  → 历史热点板块
  → 历史候选池
  → 当日复合评分
  → Top 3 / Top 5
  → 次日可成交价格
  → 止损/目标/持有期退出
```

必须避免使用未来数据，并纳入：

- 次日开盘或可成交 VWAP；
- 一字涨停和停牌过滤；
- 佣金、印花税和滑点；
- 止损触发与跳空风险；
- 当前成分股带来的幸存者偏差说明。

## P1：候选质量和可执行性

### P1-1 改进候选宇宙

每个强势板块不只取当日涨幅前列，可组合三类股票：

- 龙头：趋势和资金最强；
- 中军：流动性好、基本面相对稳定；
- 低位转强：处于有效买点、尚未大幅偏离支撑。

增加硬过滤：

- 停牌、涨停无法成交；
- 流动性不足；
- 距 MA20 或关键支撑过远；
- ATR 风险过高；
- 即将财报、解禁或存在重大不确定事件；
- 预期风险收益比不足。

### P1-2 按过滤后候选数扩池

扫描停止条件改为：

```text
通过 min_score
+ 数据覆盖门槛
+ 风险门槛
+ 市场门槛
后的有效候选数量达到目标
```

不能仅按维科夫门控后的原始数量停止扫描。

### P1-3 组合分散约束

建议默认：

- 单一板块最多 1～2 只；
- 高度相关概念合并计算暴露；
- Top 3 优先覆盖不同驱动逻辑；
- 与现有持仓高度重合时降低推荐等级；
- 多板块股票记录完整板块列表，并标注最强主线归属。

### P1-4 输出完整交易计划

每只正式推荐至少包含：

| 字段 | 含义 |
|---|---|
| 行动等级 | 可执行/等待触发/观察 |
| 入场区间 | 可接受买入价格范围 |
| 确认条件 | 突破、回踩、量能或收盘确认 |
| 无效位 | 原逻辑失效价格或条件 |
| 止损位 | 风险控制价格 |
| 目标位 | 保守/主目标/激进目标 |
| 风险收益比 | 至少达到预设阈值 |
| 仓位上限 | 结合市场环境和波动率 |
| 持有周期 | 面向 1～6 个月中线 |
| 推荐有效期 | 超时后必须重新评估 |
| 反向论据 | 最强看空证据 |
| 重要日期 | 财报、解禁、分红、政策事件 |

## P2：反馈闭环和可解释性

### P2-1 推荐快照

每日保存不可变快照，包括：

- 候选宇宙；
- 全部原始维度分；
- 数据覆盖率和数据日期；
- 市场环境；
- 最终行动等级；
- 推荐价、止损、目标和模型版本。

### P2-2 自动业绩跟踪

自动计算推荐后 5/10/20/60 个交易日：

- 绝对收益；
- 相对沪深300超额收益；
- 相对所属板块超额收益；
- 最大有利波动和最大不利波动；
- 止损/目标是否触发；
- 实际可成交性。

### P2-3 分组校准

分别统计：

- 市场环境档位；
- 维科夫子阶段；
- 置信度档位；
- 板块持续性档位；
- 龙头/中军/低位转强类型；
- Top 1、Top 3、Top 5 分层表现。

仅当样本量和显著性足够时才调整权重，避免根据少量样本过拟合。

## 5. 建议输出结构

```text
今日结论
  市场环境、是否允许新增仓位、建议总仓位

今日可执行（0～5只）
  标的、核心逻辑、入场区间、止损、目标、R:R、仓位、有效期

等待触发
  标的、触发条件、取消条件

观察池
  候选及未升级为推荐的原因

组合风险
  板块集中度、相关性、事件风险、数据缺失

数据说明
  数据截止时间、来源、覆盖率、模型版本
```

## 6. 验收指标

### 6.1 正确性

- 不使用推荐日之后的数据。
- 所有行情字段包含有效交易日。
- 盘中和盘后语义明确。
- 5/10/20/60 日收益窗口通过精确单元测试。
- 全样本基准与信号样本定义清晰且无条件污染。

### 6.2 推荐质量

- Top 3/Top 5 的 20 日平均超额收益为正。
- Top 组显著优于候选池中位组或 Bottom 组。
- 胜率、盈亏比、最大回撤同时披露。
- 不同市场环境下结果可解释，不用总平均掩盖弱市失效。
- 样本不足时明确输出“证据不足”，不强行给推荐。

### 6.3 用户可执行性

- 正式推荐不超过 5 只。
- 每只推荐均有入场、止损、目标、仓位和有效期。
- 弱市或数据不足时允许输出“今日无推荐”。
- 用户无需盯盘即可按收盘确认或条件单执行。

## 7. 推荐实施顺序

1. 增加数据日期、新鲜度、覆盖率和盘中/盘后标识。
2. 修正回测窗口、基准样本和对应测试。
3. 将市场环境从提示升级为硬门控。
4. 增加板块绝对门槛和多日持续性。
5. 调整扩池停止条件，并加入组合分散约束。
6. 将报告拆为“可执行/等待触发/观察池”。
7. 增加入场、止损、目标、仓位和有效期。
8. 保存每日推荐快照并自动跟踪实际表现。
9. 根据足够样本校准阈值和权重。

## 8. 非目标

- 不发展高频或日内 T+0 推荐。
- 不为了凑足推荐数量而降低数据质量和风险门槛。
- 不仅凭单日涨幅或单一维科夫信号给出买入结论。
- 不在未经回测验证前宣称评分具有稳定预测力。

本方案及其后续生成的分析仅供学习参考，不构成任何投资建议。股市有风险，投资需谨慎。
