## 1. 背景与结论

当前“今日推荐”的生产链路为：

```text
当日热点板块
  → 板块成分股硬过滤
  → 维科夫买点漏斗
  → 动量/量价/资金/基本面/板块/维科夫复合评分
  → Top 30 每日候选表
```

该流程已经具备候选发现能力，但当前输出更接近“候选股排行榜”，尚不足以直接称为“今日推荐”。主要差距不在页面样式，而在以下四点：

1. 数据新鲜度和数据覆盖率没有成为推荐硬门槛。
2. 市场环境目前主要用于提示，没有真正约束推荐数量和行动等级。
3. 热点和复合评分尚未经过完整生产链回测校准。
4. 候选发现输出不承担入场区间、失效条件、止损、目标、仓位和有效期等执行要素。

优化目标应从“今天分数最高的股票”升级为：

> 在当前市场环境下，筛出证据充分、能够成交、风险边界明确，并经过历史验证的少数中线机会。

## 2. 当前实现观察

### 2.1 数据新鲜度现状

- `stock_scanner._fetch_kline()` 仍可能先读取旧缓存，但推荐质量门会按最近有效依据日检查最后交易日，旧 K 线不得升级为推荐。
- 基本面缓存会输出并校验抓取日期；旧抓取结果不计入覆盖率。后续仍可优化为过期时主动刷新，而不是只在资格层淘汰。
- 市场环境日期必须与推荐依据日匹配；周末和盘前允许使用最近交易日收盘数据。
- 09:30–15:00（包括午间休市）统一标记为盘中临时版；推荐层级仍按市场环境档位决定，收盘后再确认。

### 2.2 热点板块现状

- `min_hot` 已按绝对热度生效，同时保留相对排名用于排序，不再用相对第一名自动代表强势。
- `/candidates` 读取 3/5/10 日快照并结合相对沪深300强弱；历史不足的单日脉冲只能观察。
- 涨停/LHB 分数存在时会进入共振分，缺失时按中性处理并由持续性门控兜底。
- 成分股接口仍按当日涨幅排序后只取前若干只，追涨偏差和龙头/中军/低位转强宇宙留待 P1。

### 2.3 候选扩池现状

- 扫描按质量调整分、数据资格和板块持续性资格后的有效数量决定停止，不再按原始维科夫候选数停止。
- 当前排序仍没有行业集中度和相关性约束，Top 结果可能集中在同一主题。
- 股票属于多个板块时，去重逻辑仍只保留首次遇到的板块归属，完整板块列表与最强主线归属留待 P1。

### 2.4 缺失数据被视为中性数据

资金、基本面等数据缺失时原始分仍为兼容消费者保留 50 分语义，但推荐排序改用质量调整分，使“没有证据”通过覆盖率和新鲜度因子受到惩罚。

建议将结果拆分为：

```text
raw_score              原始方向/强弱分
coverage               必检数据覆盖率
data_quality           数据质量与新鲜度
confidence             信号可信度
quality_adjusted_score 质量调整后的最终排序分
```

### 2.5 回测闭环不完整

现有 `/wyckoff-backtest` 主要验证维科夫买点，而不是完整的“热点板块→候选→复合排序→Top K”生产链。

P0 已复核并修正两个实现细节：

- 前向收益命中目标日期时改用目标日首个可用收盘价，并增加 20/60 日精确值断言。
- 全样本基准不再依赖维科夫阶段识别成功，避免由分类成功与否造成选择偏差。

此外，当前模拟未纳入次日实际成交、涨停无法买入、手续费、滑点、止损和组合约束。

## 3. 目标产品形态

“今日推荐”应分成三层，而不是输出一张 20～30 只股票的等价列表。

### 3.1 今日可执行

最多 3～5 只，同时满足：

- 市场环境允许建仓。
- 板块具有绝对强度和持续性。
- 核心数据覆盖率达到门槛。
- 维科夫买点及复合评分通过历史校准阈值。
- 风险收益比达标，且不存在无法成交、重大事件临近等硬风险。

### 3.2 等待触发

逻辑成立，但价格尚未满足入场条件。明确给出：

- 突破确认价；或
- 回踩承接区间；以及
- 触发失效日期。

### 3.3 观察池

保留原有 20～30 只候选发现能力，但明确标注不能直接行动的原因，例如：

- 市场环境偏弱；
- 数据覆盖不足；
- 板块持续性不足；
- 距离支撑过远；
- 风险收益比不足；
- 重大事件临近。

## 4. 分级优化方案

## P0：可信度和正确性

### P0-1 数据新鲜度硬门槛

为行情、资金、基本面、市场环境统一增加：

- `data_date`
- `fetched_at`
- `source`
- `quality`
- `stale_reason`

推荐规则：

- K 线必须覆盖最近有效交易日。
- 市场环境必须匹配当前推荐所依据的交易日。
- 资金数据超过允许时效后降权或淘汰。
- 关键维度缺失时不得进入“今日可执行”。
- 盘中输出统一标记为“盘中临时版”；强势市场可进入“今日可执行”，中性市场可进入“等待触发”，但均需收盘后复跑确认，且不写入正式推荐历史。正式推荐默认在收盘后生成，或盘前使用上一交易日收盘数据。

### P0-2 市场环境硬门控

建议规则：

| 市场环境分 | 输出等级 | 推荐数量 |
|---|---|---:|
| `<60` | 仅观察 | 0 |
| `60–79` | 等待触发 | 0～2 |
| `≥80` | 正常推荐 | 3～5 |
| 缺失/过期 | 降级 | 0 |

市场环境不应只是报告提示，而应直接影响候选行动等级和推荐数量。

### P0-3 热点板块绝对门槛

同时保留绝对分和相对排名：

```text
sector_score =
  当日绝对热度
  + 3/5/10日持续性
  + 相对沪深300强弱
  + 资金持续性
  + 涨停/LHB共振
```

要求：

- 修复或移除未生效的 `min_hot` 参数。
- 禁止仅凭 min-max 后的相对高分认定强势板块。
- 区分“中期主线”“新兴主题”“单日脉冲”。
- 单日脉冲默认只进入观察池。

### P0-4 数据质量调整评分

不再用固定 50 分代表缺失数据。建议：

```text
final_score = raw_composite_score × coverage_factor × freshness_factor
```

最低要求示例：

- K 线：100% 必需。
- 资金或基本面：至少一个完整，另一个不得为错误状态。
- 市场环境：必须有效。
- 总覆盖率低于 70%：只能进入观察池。

### P0-5 修正并升级回测

先修正：

1. 前向收益持有期的精确日期定义。
2. 全样本基准的采样范围。
3. 测试用例必须断言精确收益值，而不只是断言返回浮点数。
4. 将 `test_wyckoff_backtest.py` 接入主质量门。

随后增加完整生产链回测：

```text
历史当日可见数据
  → 历史热点板块
  → 历史候选池
  → 当日复合评分
  → Top 3 / Top 5
  → 次日可成交价格
  → 止损/目标/持有期退出
```

必须避免使用未来数据，并纳入：

- 次日开盘或可成交 VWAP；
- 一字涨停和停牌过滤；
- 佣金、印花税和滑点；
- 止损触发与跳空风险；
- 当前成分股带来的幸存者偏差说明。

## P1：候选质量和可执行性

### P1-1 改进候选宇宙

每个强势板块不只取当日涨幅前列，可组合三类股票：

- 龙头：趋势和资金最强；
- 中军：流动性好、基本面相对稳定；
- 低位转强：处于有效买点、尚未大幅偏离支撑。

增加硬过滤：

- 停牌、涨停无法成交；
- 流动性不足；
- 距 MA20 或关键支撑过远；
- ATR 风险过高；
- 即将财报、解禁或存在重大不确定事件；
- 预期风险收益比不足。

### P1-2 按过滤后候选数扩池

扫描停止条件改为：

```text
通过 min_score
+ 数据覆盖门槛
+ 风险门槛
+ 市场门槛
后的有效候选数量达到目标
```

不能仅按维科夫门控后的原始数量停止扫描。

### P1-3 组合分散约束

建议默认：

- 单一板块最多 1～2 只；
- 高度相关概念合并计算暴露；
- Top 3 优先覆盖不同驱动逻辑；
- 与现有持仓高度重合时降低推荐等级；
- 多板块股票记录完整板块列表，并标注最强主线归属。

### P1-4 交易计划（暂不纳入 `/candidates`）

当前 `/candidates` 只负责候选发现和分层，不生成或展示交易计划，也不以交易计划完整性作为推荐资格门槛。`candidate-trade-plan/v1` 及其通用校验能力保留给需要执行计划的独立工作流；若未来重新接入候选报告，必须单独定义输出范围、门控和回测证据。

## P2：反馈闭环和可解释性

### P2-1 推荐快照（已实现 v1）

每日保存不可变快照，包括：

- 候选宇宙；
- 全部原始维度分；
- 数据覆盖率和数据日期；
- 市场环境；
- 行动等级、推荐数量限制和模型版本。

正式快照路径为 `.cache/stock-trend/recommendation_history/YYYY-MM-DD.json`，采用 canonical JSON 摘要和同文件系统 hard-link write-once：同内容重复保存为 no-op，同日不同内容抛出冲突且不覆盖。临时/盘中结果不进入官方快照。

### P2-2 自动业绩跟踪（已实现基础 v1）

自动计算推荐后 5/10/20/60 个交易日：

- 绝对收益；
- 相对沪深300超额收益；
- 相对所属板块超额收益；
- 最大有利波动和最大不利波动；
- 分层表现与候选池对比；
- 数据质量和实际可成交性（若有独立执行计划）。

归因引擎位于 `scripts/analysis/recommendation_attribution.py`，使用 T+1、市场交易日、前复权输入、evaluation cutoff、停牌/一字涨停/止损优先规则；结果写入独立可变 sidecar。默认成本为 gross/zero，成本参数显式传入。样本少于 20 个正式日期或 100 个成熟信号时，汇总保持 `evidence_insufficient`。

### P2-3 分组校准

分别统计：

- 市场环境档位；
- 维科夫子阶段；
- 置信度档位；
- 板块持续性档位；
- 龙头/中军/低位转强类型；
- Top 1、Top 3、Top 5 分层表现。

仅当样本量和显著性足够时才调整权重，避免根据少量样本过拟合。

## 5. 建议输出结构

```text
今日结论
  市场环境、推荐模式、推荐数量

今日可执行（0～5只）
  标的、核心逻辑、短线买点、数据质量

等待触发
  标的、触发条件、取消条件

观察池
  候选及未升级为推荐的原因

组合风险
  板块集中度、相关性、事件风险、数据缺失

数据说明
  数据截止时间、来源、覆盖率、模型版本
```

## 6. 验收指标

### 6.1 正确性

- 不使用推荐日之后的数据。
- 所有行情字段包含有效交易日。
- 盘中和盘后语义明确。
- 5/10/20/60 日收益窗口通过精确单元测试。
- 全样本基准与信号样本定义清晰且无条件污染。

### 6.2 推荐质量

- Top 3/Top 5 的 20 日平均超额收益为正。
- Top 组显著优于候选池中位组或 Bottom 组。
- 胜率、盈亏比、最大回撤同时披露。
- 不同市场环境下结果可解释，不用总平均掩盖弱市失效。
- 样本不足时明确输出“证据不足”，不强行给推荐。

### 6.3 用户可执行性

- 正式推荐不超过 5 只。
- 每只候选均有名称、板块、短线买点和数据质量说明。
- 弱市或数据不足时允许输出“今日无推荐”。
- 报告用于收盘复核候选，不直接提供下单参数。

## 7. 推荐实施顺序

1. 增加数据日期、新鲜度、覆盖率和盘中/盘后标识。
2. 修正回测窗口、基准样本和对应测试。
3. 将市场环境从提示升级为硬门控。
4. 增加板块绝对门槛和多日持续性。
5. 调整扩池停止条件，并加入组合分散约束。
6. 将报告拆为“可执行/等待触发/观察池”。
7. 保存每日候选快照并自动跟踪实际表现。
8. 根据足够样本校准阈值和权重。

## 8. 非目标

- 不发展高频或日内 T+0 推荐。
- 不为了凑足推荐数量而降低数据质量和风险门槛。
- 不仅凭单日涨幅或单一维科夫信号给出买入结论。
- 不在未经回测验证前宣称评分具有稳定预测力。

## 9. 免责声明

本方案及其后续生成的分析仅供学习参考，不构成任何投资建议。股市有风险，投资需谨慎。
