# 日线弱转强板块展示计划

## 目标与范围

让今日推荐 HTML 的“日线弱转强”板块单元格复用观察池的板块标签、热度颜色、持续性和来源展示；保留该表独立扫描得到的板块关系，不改变信号、排序或推荐资格。Markdown 和 JSON 的内容保持兼容。

## 实施步骤

1. 将 `scripts/scans/daily_candidates.py` 中 `_sector_text`、`_sector_persistence_text` 和 `_sector_html` 提取到 `scripts/reporting/` 下的共享展示模块，观察池调用同一实现，避免两个版本漂移。保持当前标签颜色阈值、转义和缺失值行为。
2. 在 `scripts/reporting/weak_to_strong.py` 的 HTML 渲染中，将每个有效 `sector_memberships` 项映射为共享渲染器所需字段（包括名称、热度、持续性、排行及成分来源）。逐项展示已有板块，缺失数据按现有规则省略，不凭空补热度或历史；无有效名称时保留“未记录”。共享渲染器只负责展示，不改变原始数据或选取资格。
3. 在现有弱转强表格样式中安排多个板块标签及其说明的间距和自然换行，延续表格的横向滚动。检查观察池样式和内容没有变化。
4. 扩展 `tests/test_weak_to_strong_integration.py`：覆盖多板块、不同热度、持续性与来源、缺失数据、特殊字符转义，并验证弱转强和观察池对相同板块证据输出一致；验证 Markdown、JSON 和正式分桶保持原样。

## 验收与验证

- 同一板块证据在两处使用相同的标签样式、热度分档和说明；多个板块均可辨认，不截断，不因缺失热度伪造数据。
- 股票名、板块名和来源中的 HTML 特殊字符安全转义；无板块时显示“未记录”。
- 分别检查宽屏和窄屏下的长板块名、多板块、长来源说明；窄屏可横向滚动，内容不重叠。
- 先运行针对性的弱转强集成测试，再运行项目要求的 `bash tools/python.sh .claude/skills/stock-trend/tests/test_stock_trend.py` 和 `bash tools/python.sh .claude/skills/stock-trend/tests/test_golden.py --diff`。实时接口测试遵守本机运行契约；不为消除失败而刷新 golden。

## 风险与处理

- 弱转强记录来自独立扫描，可能没有观察池主板块的全部字段：只展示真实可用证据，缺失值不冒充已验证；不将当前正式候选的字段按代码回填到独立记录。
- 多板块与来源说明可能增加行高：允许自然换行并保持表格滚动，避免裁剪信息。
- 抽取公共函数可能改变观察池：用相同输入的渲染回归检查确保输出不变。
