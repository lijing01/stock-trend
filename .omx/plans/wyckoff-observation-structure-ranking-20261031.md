# 维科夫观察池：近期表现、结构判断与排序改进计划

2026-10-31；Direct Plan。只研究与规划，不修改生产算法。

## 1. 需求与结论

目标：让观察池优先呈现“当前证据可靠、结构健康、供需确认更充分、距离失效位合理”的标的，并解释何时等待、何时降级。结构标签、执行资格与观察优先级分别判断。不能把形态置信度当胜率、把历史确认当当前健康、把一级/二级/三级当收益排名。

建议先修结构资格一致性，再添加结构风险距离和回踩证据的影子排序。现有Spring/SOS/LPS/BU因果识别、事件健康、长期/短期背景、年龄及入场时机均已存在；本计划复用这些能力，不重建检测器，也不直接根据本批收益拟合新权重。

- 使用当时保存的结构标签，没有用后续价格重标信号；行情是后取得的历史缓存，仍可能有复权修订。没有同期间指数/行业基准，因此这里只能描述绝对表现，不能分离市场下跌与算法增益，也不证明中线策略无效。

## 3. 典型案例与结构解释

1. **移远通信，10-23，排名1，JAC。** confidence=0.90、entry_fresh、confirmed_holding；当前80.74，触发收盘83.72，负偏离-0.7067 ATR；原阻力63.66，acceptance_floor=62.1325，当前ATR=4.2167。收盘距原阻力约4.05 ATR，距结构底约4.41 ATR（约23.0%）。后5日-20.30%、MAE -20.82%。当前规则没有逻辑矛盾：仍高于旧阻力，所以结构未失效；但结构止损空间很大，触发收盘偏离很小并不能证明风险合理。需要“事件触发位、原箱体边界、失效位”三套坐标独立呈现与评价。
2. **内蒙新华，10-15，排名1，JAC。** 已是entry_wait_pullback、executable=false，仍凭总分居观察池首位；后5日-24.86%。这不是错误放行正式买入，而是观察排序未让用户直观看到“首突破待回踩”的优先级限制。应分层展示，不把大综合分当即时准备度。
3. **华峰测控，10-15，排名29，Spring。** 当日新信号、entry_fresh、confidence=0.81、长期结构未知；5日-15.80%。单日收复形态不能代表后续需求持续。需把“事件已发生”与“后续测试/需求证据成熟”分别保存，观察是否需要等待确认。
4. **迪安诊断，10-16，排名4，LPS。** 5日+16.26%，但MAE -5.10%；前日另有follow_through_weakened记录。应审计是否为新事件/再确认、为何升级，并规范父周期身份。不能仅因后来上涨撤销当时转弱状态，也不能将相邻两天视为完全独立成功。

这些是诊断案例，不是用个股事后走势制定特例规则；生产代码是否当时已同版本须从模块哈希进一步核实。

## 4. 结构判断的改进合同

### 4.1 先修资格一致性（P0）

`analysis/wyckoff.py:1186-1250`已有period alignment，但`:1222-1225`把缺失年龄默认为0，缺失signal_status默认confirmed；而`:285-308`的买点等级对缺失年龄拒绝。`:1619-1628`的is_buy_point缺年龄下界。统一严格解析缺失、负值、布尔、非整数和非法文本；不能缺字段即“当日确认”，也不能因非法文本直接崩溃。既有合法记录语义保持。is_buy_point的双参数默认值是显式旧接口兼容，实施前盘点调用方：可保留旧接口用于历史解释，但正式资格路径必须传完整证据，不全局修改默认值导致无关行为变化。

统一读取event_health和entry_timing：未知健康不得升级为confirmed_holding；当前健康与执行状态矛盾时输出诊断并取消执行加分，保留历史标签。测试缺失证据、错range、旧快照以及健康变化场景。

### 4.2 保留四个独立判断维度（P1）

- **背景**：长期吸筹/上涨、派发/下跌、未知；长期箱体不存在不等于没有价格趋势。已有alignment维持，额外趋势描述仅作旁证，不补造“吸筹”。
- **事件证据链**：Spring发生；Spring后Test确认；首次SOS/JAC；SOS后LPS/BU回踩确认；回踩后再确认。每个状态保留事件日、检测日、父箱体、参考位及known_at。Secondary Test不能仅凭名字冒充Spring后的成功Test，须父事件可关联。BU无本批样本，仅增加语义测试，不给业绩加分。
- **当前健康**：持稳、待回踩、后续转弱、突破失败、结构失效、证据未知。复用现有健康状态，不把所有负偏离当转弱。
- **位置与风险**：分别计算到触发收盘、当前有效支持/原阻力、冻结失效位的ATR距离，以及下一已知压力的空间。必须同事件、同复权基准、as-of一致；没有可靠上方压力时risk/reward为空，不凭目标价补造盈亏比。

现有`evaluate_confirmed_spring_health`（`:694-745`）收盘破Spring低点才判失效；`evaluate_confirmed_jac_health`（`:748-817`）以原阻力和结构floor判断JAC；`evaluate_confirmed_lps_health`（`:535-634`）已区分触发低点转弱与结构破坏。新增的是可审计的供需持续性和风险距离，不放宽这些失效线。

Spring新增影子证据：收复后是否持续守住支持、后续回测量能相对事件前基准是否收缩、是否出现需求跟进；待后续K线出现才能升级，不回填到Spring当日。JAC新增影子证据：首次突破/回踩后再确认分类、距原阻力过远、回踩中量能与波幅变化；不把低于触发收盘自动视为廉价，也不自动惩罚正常回踩。

连续确认几日、缩量比、距离多少ATR为偏远，先注册少量单因素研究阈值（例如距离1.5/2/3 ATR），不据单只移远样本决定正式阈值。冻结事件ATR与当前ATR同时保存，前者用于稳定风险尺度，后者用于当前波动描述。

## 5. 建议的观察排序：分层，再在层内比较

生产基线保持现有`quality_adjusted_score + strict_buy_point_bonus`（`scans/daily_candidates.py:223-255,415-419`）。已有timing_score、age_penalty、extension_penalty，但最终分数没有连续使用这些值，只通过不可执行时取消bonus起作用。结构分与额外奖励可能边际重复，需消融，不先断言有错。

新候选仅做影子版本：

|层|进入条件|用途|
|---|---|---|
|A：确认链完整、当前健康|有可关联的回踩/测试/再确认；证据完整且健康；入场时机无硬阻断|重点跟踪，仍须市场与正式资格判断|
|B：结构健康、确认未成熟|初次Spring或SOS/JAC，后续测试/回踩未完成；或已有结构但当前需等待|观察下一步条件，不与A混成一个“可买”分数|
|C：转弱或待重新评估|follow_through_weakened、retest_pending、过期、证据未知等分别保留原因|跟踪是否修复；证据未知不称转弱|
|历史诊断|failed_breakout、structure_invalidated|移出活跃优先列表，保留追踪与审计|

A优先于B只是需要验证的“成熟度优先”候选，不是已证实的收益排序；若确认过迟丧失收益，评估应能否决它。初次Spring仍展示，不一刀切删除。

层内排序候选采用透明的稳定排序元组，先不拟合几十个权重：
1. **风险距离档**：已知且在实验限定风险范围内、已知但风险偏大、未知；基于冻结失效位，不只用触发收盘。未知不是无限大风险，单列标记。
2. **供需确认质量档**：由可重复的check生成，Test回测是否守位、量价是否支持；不直接比较不同形态的原始量比。
3. **时机状态/年龄档**：fresh、waiting、stale/unknown分开；年龄基于检测/确认日，后续确认不能追溯成可提前买入。组内再比较已有timing_score，但对负偏离另审健康，避免把跌得多误当时机满分。
4. **原质量分**作为次级排序，再按证券代码稳定兜底；置信度只解释识别证据，不显示为成功概率。

集中度先作为报表诊断，本轮不同时引入行业硬上限，以免无法归因。各层展示实际数量，不强制凑满A层或30只。
