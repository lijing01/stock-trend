# 每日复盘五项评分详情链接方案

## 需求与范围

为每日复盘的「大盘趋势、成交额、赚钱效应、涨停情绪、资金」每行增加一个「查看详情」超链接；详情包含本报告评分口径与对应财经网站行情入口。覆盖未来生成的 HTML/Markdown，以及指定的 `reports/lists/daily-review-20261003-164458.html` 和同名 Markdown。用户已要求执行，实施与验证完成。

用户所述「东方采访」按上下文理解为东方财富。优先选择与现有数据来源一致的东方财富，必要时使用同花顺；腾讯作为已验证后的补充入口，不要求为每项凑齐三家渠道。

## 现状依据

- 五项摘要表的 Markdown 在 `scripts/analysis/market_regime.py:1372`，HTML 行生成在同文件 `:1842`，表格在 `:1884`；路径均相对于 `.claude/skills/stock-trend/`。
- 正式趋势指数为上证、沪深300、深成；成交额使用上证＋深证综指，见 `scripts/analysis/market_regime.py:153`。成交额链接不能误用深成指替代深证综指。
- 五项分数由本项目计算，口径见 `scripts/analysis/market_regime.py:379`–`:501`。财经网站提供行情与排名，不能声称展示本项目的 0.0/17.6/49.5/70.6/42.1 分。
- 涨跌家数和主力净流入按东方财富地域板块加总，见 `scripts/analysis/market_regime.py:337`；赚钱效应还含行业上涨比例，见 `:431`。不同平台股票覆盖范围和资金算法可能不同。
- 已有冻结评分解释的 HTML/Markdown 渲染器为 `scripts/reporting/market_explanation.py:43`、`:85`。复用其现有证据显示，不增加新的评分计算和采集链路。
- 目标历史报告 `:23` 已明确：指数/成交额依据 2026-09-30，其余来源缺事件时间戳；`:28` 为五项摘要，`:30` 为评分解释。增加链接不能消除这项时间限制。
- 同路径读改写锁与原子落盘已有 `scripts/core/report_file.py:15`、`:28`；历史报告更新可参考 `scripts/reporting/us_market_summary.py:452` 的锁内重读、日期校验及备份做法。

## 推荐交互

摘要表增加第四列「详情」，五行各一个锚点链接，例如 `[查看详情](#market-detail-index-trend)`，点击跳到评分解释后的对应详情。每节提供「返回评分表」。HTML 使用普通锚点，不依赖 JavaScript；Markdown 使用相同稳定 ID 并验证实际渲染器支持显式锚点。

每节顺序：指标名称 → 本报告分数与说明 → 本报告依据日/来源时间状态 → 评分口径 → 财经行情入口。外链使用有意义的名称，如「东方财富·沪深300日K」，在新标签页打开，带 `rel="noopener noreferrer"`。入口旁明确写「外部最新行情；历史值需自行选择日期」，只有确实支持且验证过日期参数的网页才标为历史直达。

| 组件 | 详情内容 | 外部入口目标 |
|---|---|---|
| 大盘趋势 | 三指数相对 MA20 的状态、每项资格；有冻结收盘/MA20则显示，无则注明未记录 | 上证、沪深300、深成指日K/指数行情 |
| 成交额 | 两市成交额、20日均额与变化比例的计算口径；均额缺失不从四舍五入的 -22% 倒算 | 同花顺两市成交总额；上证＋深证综指日K作为核验后补充 |
| 赚钱效应 | 涨跌家数、行业上涨占比；本项目按地域板块统计涨跌家数 | 沪深A股涨跌排行、行业板块排行 |
| 涨停情绪 | 涨停数、连板数、最高板、绝对家数/历史基线与连板加成 | 涨停池/涨停复盘；存在可验证历史日期筛选则说明如何使用 |
| 资金 | 全市场主力净流入、地域板块加总口径，不解释为北向资金 | 大盘资金流、地域/板块资金流 |

### 外部来源核验

实施前锁定经官方网页验证的 HTTPS 链接，确认股票/指数代码与页面名称一致、目标栏目相关。具体来源证据在本计划末尾补充。网站首页、搜索结果和裸 API 不作为详情主入口；若专业栏目必须登录则标注，不能静默替换成不相关页面。

## 实施步骤

1. **集中定义来源与口径。** 新建小型 `scripts/reporting/market_detail_links.py`，集中维护五项 ID、标题、说明及已验证外链；提供 HTML/Markdown 详情与摘要链接渲染。仅消费冻结上下文/解释对象；固定 HTTPS 来源白名单，文本转义。不给评分计算或 `market_explanation/v1` 添必需字段，兼容旧缓存。
2. **接入新报告。** 修改 `scripts/analysis/market_regime.py:1355` 和 `:1828`，在摘要表增加详情列，在现有评分解释之后插入五个详情节及统一时间说明。仅每日复盘接入，不自动扩散到候选/个股报告。不增加联网采集；`--no-refresh` 和离线生成均可渲染链接。
3. **补充指定旧报告。** 增加窄入口 `scripts/bridge/review_detail_links.py --html-path ... --basis-date 2026-09-30`。从该报告现有日期、五项行及冻结解释提取展示信息，禁止用全局最新缓存覆盖历史。旧报告没有原始字段时只复述已存说明/通用计算口径，注明原值未保存。严格验证报告类型、依据日和五项唯一性；不符合结构则拒绝写入。使用限定区块标记及稳定锚点，重复运行不追加。HTML 与存在的同名 MD 先分别验证，再按统一 HTML→MD 锁顺序重读、一次备份 `.pre-detail-links`、原子写入；单文件原子性不等于两文件事务，失败需给出写入状态，允许重跑恢复。保留休市提示、美股区块、观察列表与数值。
4. **验证与文档。** 在 `tests/test_market_explanation_reporting.py` 或新 `tests/test_market_detail_links.py` 增加针对链接映射、历史更新及冻结行为的测试；在 `references/daily-review.md` 说明详情入口、外部历史查询限制和旧报告补充命令。

## 验收标准

- HTML/Markdown 摘要五行各有且仅有一个「查看详情」，对应五个唯一详情 ID；点击能到达对应段落并可返回。
- 大盘趋势覆盖 `000001.SH/000300.SH/399001.SZ`；成交额明确计算使用 `000001.SH/399106.SZ` 并提供两市成交总额入口，深证综指直链只有核验通过后才加入；赚钱效应同时提供市场涨跌与行业入口。
- 所有外链是已核验的官方 HTTPS 页面，显示渠道和栏目；不拼装未经证实的历史日期参数，不要求自动打开 GUI。
- 详情忠实保留冻结分数、说明、依据日与来源时间未知的限制；原始字段缺失明确标注，不伪造历史明细、均额、MA20或涨停名单。
- 报告生成与旧报告补充无需联网。禁用网络时测试仍通过，五项分数、综合分、缓存和评分历史不变。
- 指定旧报告更新后休市备注、美股概要和观察列表保留；重复更新结果一致；错日期/缺行/重复行不写；并发观察列表更新不丢内容。
- 在 375px 与 1440px 下检查新增详情入口与详情区域可读、键盘可访问，新增内容不扩大页面既有横向溢出。

## 风险与处理

- **历史错配：** 动态财经页面默认最新行情。明确外链时间属性，历史快照以报告已保存证据为准；来源时间未知仍显示未知。
- **口径差异：** 跨渠道资金、涨跌数和涨停池可能不同。与现有采集源同渠道优先，在详情说明覆盖范围和统计方法，不拿第三方列表强行修正本报告分数。
- **网页变更/反爬/JS：** 自动请求成功不能证明交互数据完整；记录验证程度。失效来源通过集中配置替换，离线生成不受影响；不绕过登录、也不新增爬虫。
- **历史补丁误改：** 限定报告类型/日期/组件、备份、幂等标记、共享锁、原子落盘；不使用宽泛正则重写整页。
