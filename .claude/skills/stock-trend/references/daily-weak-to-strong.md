# 日线弱转强观察

今日推荐在现有板块成分扫描中，独立计算日线弱转强；表格显示“缩量待突破”、当日收盘确认和盘中临时形态。结果仅覆盖实际扫描到的普通 A 股，数据不足和范围不完整会单独标示。该形态不改变维科夫筛选、正式分桶、排序或市场硬门槛。

报告先合并当日形态和上一交易日信号跟踪，仅在证券代码及周期标识均一致时关联。Markdown/HTML 主表只展示报告依据日一致、`evidence_status=ready`、已收盘且周期未失效或待复评的形态；仅有历史跟踪、日期不一致、盘中临时、失效、待复评和数据不足的记录只计入诊断。主表按收盘确认或增强、缩量待突破或延续、结构有效回调分层，同层比较可用的 MA10/MA20 方向、风险和该背景的形态质量，按证券代码稳定去重后全表最多展示 30 只，不足 30 只不补入低资格记录。名称/代码旁只展示有证据的跟踪次数，同日重跑不递增。跟踪状态和数据资格不代表正式推荐资格。

报告顶部显示扫描行数、有效证券数、展示数和未展示数，表内给出全局名次和入选依据，诊断折叠区汇总排除原因。JSON 保留完整原始形态、跟踪和诊断数组，不按主表 30 只上限截断；另在 `display_selection` 保存与 Markdown/HTML 相同的限额、统计、名次、代码、周期和入选依据。资金、新闻和基本面因全池证据覆盖不一致，不参与首版主表排序。

v1 使用评价日 MA10、MA20 相对三个交易日前同周期均线的变化率判断方向；变化率大于 0.002 视为上行。K 线不足时斜率为空，历史记录未保存方向时显示“均线方向未记录”。方向参与同阶段观察表排序，不改变形态判定或正式推荐。

合同 `daily-weak-to-strong/v1`：连续至少 2 个收盘价逐日上涨的交易日形成上涨段，末日为 D0；第一根收盘不再上涨的日线为 D1。D5 为最后突破机会。调整期最低价相对 D0 最高价回撤不超过 12%，每个调整日收盘守住 0.98×MA10；调整均量不超过上涨段均量的 0.8 倍，调整至少 2 日时末日成交量不超过调整均量的 0.9 倍。

MA10 支撑检查记录调整期相对支撑阈值余量最小的日期、收盘价、MA10、阈值和余量；余量为收盘价除以阈值减一。突破日不属于调整期。数值按未舍入数据判断，报告数值仅作展示；旧记录没有依据时不补造。

突破前调整区间最高价为 H、最低价为 L、平均量为 Va。突破日收盘须严格高于 H、成交量至少为 Va 的 1.2 倍、收盘位置不低于 0.75，且收盘价不超过 1.05×H；一字线不确认。H、L、Va 不包含突破日。一旦价格突破但其他条件失败，本周期失效；不能用 D6 延长旧周期。形态阈值是待回测初值。

`SUPPLY_DRY` 表示缩量待突破；`BREAKOUT_CONFIRMED` 需要可靠的当日收盘及日历证据；`PROVISIONAL_BREAKOUT` 是盘中临时突破。盘中生成报告时必须主动刷新最新日线 K 线，并用包含目标交易日当时价量的快照计算所有状态；缩量、回调和突破均设置 `provisional=true`、`confirmation=provisional`，只能作为盘中临时观察。盘中成交量是快照时点的当日累计量，不能推断为全日量能；报告展示数据来源和实际获取时间，收盘后必须重新运行。

盘后先验证目标日期、来源完成标志或可信的盘后获取证据，再使用当天最终日线。无法证明收盘时，回放历史已完成日线并以 `close_unconfirmed` 单列诊断，不能把历史状态当作当日判断，也不能产生收盘确认。过期 K 线、刷新失败、缺失复权依据、交易日历缺口、历史不足等属于真实数据不足；仅“尚未收盘”或“收盘未确认”不等同于数据缺失。汇总采用三个互斥主分类：扫描总数等于已评估、数据不足与收盘未确认之和；盘中临时是已评估的子集，盘后收盘未确认当天未完成评估。公共取数链仍要求至少 60 根有效日线，未达到者标记数据不足。

旁路结果、日线输入和交易日历保存在 `.cache/stock-trend/weak_to_strong/` 的内容寻址快照；写入失败会在结果中标明。报告中的 H/L 是结构参考值，不是委托价格。此模块不推断成交、持仓、退出或收益；次日订单和持仓管理需独立交易研究。

## v2 研究观察

`daily-weak-to-strong/v2` 是与 v1 并行的研究合同，当前验证状态为 `continue_accumulating`，不会替换默认 v1 展示或改变正式推荐资格。v2 将背景、阶段、数据资格与风险分别保存：背景为短线强势回调、平台/趋势整理、深回撤修复；阶段按准备观察、早期修复、局部转强、区间突破递进。同一周期升级阶段只计一个周期，主表同股只展示一个匹配，其他背景保存在 `secondary_matches`。

报告先按区间突破、局部转强、早期修复、准备观察分组。主表仅保留当日数据合格、已收盘且未跌回触发位的证券；跨阶段按证券代码去重并共享 30 个展示名额。组内依次比较 MA10/MA20 方向、是否偏离较大、背景与该背景自己的结构质量，最后按代码稳定排序。双均线上行只影响同阶段顺序，不把较低阶段提升到较高阶段；不同背景不横向比较 Va/V0。

均线位置与方向、H5/H10/H20、冻结父结构高点、量/前5日均量、收盘强度、风险和依据日均独立展示。滚动高点不代替父结构高点；价格突破但量能或收盘强度不足时只保留诊断证据。`extended`、`weak_volume`、`lost_level`、`parent_overhead` 和 `flat_bar` 是风险标签，不等同于数据不足。

v2 短线回调候选使用 v2 实际评价的 K 线及其均线参数重新计算方向，与其他 v2 背景一致；不会直接使用可能缺失或日期不匹配的 v1 指标。未确认收盘时不使用当日未确认 K 线。

v2 的 Markdown 与 HTML 使用相同的分组、选择和排序。JSON 保留各阶段完整原始数组，并在 `display_selection` 附加与报告一致的选择结果。当前研究版明确显示验证状态；达到冻结样本、留出覆盖和硬约束前保持 `continue_accumulating`。
