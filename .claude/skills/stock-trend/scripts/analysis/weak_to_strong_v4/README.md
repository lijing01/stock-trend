# 弱转强 V4

每日候选扫描使用本目录的 V4 实现，复用扫描阶段采集的日线和收盘确认数据。输出为 `weak_to_strong_v4`，T1、T2 分组按模型预期净收益及胜率分别排序；V4 只处理当日新确认事件。

提供包含 T1/T2 模型及完整版本、日期和哈希信息的 V4 bundle JSON：设置环境变量 `STOCK_TREND_V4_BUNDLE` 为文件路径，或向 `daily_candidates.py` 传入 `--weak-to-strong-v4-bundle 路径`。命令行参数优先。模型缺失、无效、过期或特征不足时，报告显示状态与原因，不生成伪造的 V4 排名。本目录不附带训练好的模型，源算法仍是研究版本；模型效果需独立验证。

旧版弱转强的快照和跟踪不会作为 V4 的历史结果使用，当前 V4 报告不提供跨日跟踪。
